## ✨ Features

- **Dynamic Theme Engine**: 6 hand-crafted academic themes (*Indigo*, *Emerald*, *Crimson*, *Ocean*, *Amber*, *Slate*) with automatic `localStorage` persistence.
- **Research Showcases**: Features 5 flagship projects spanning High-Dimensional Optimal Transport (`FlowLOT`), 4i Chromosome Analysis, Nuclear Morphometry, and cIF Autofluorescence Correction.
- **Publications & Citations**: Direct links to Google Scholar, arXiv preprints, DOIs, and journal articles.
- **Teaching & Talks**: Full academic teaching records from CUET and invited presentations at SASCO and CYTO.
- **Zero-Dependency Architecture**: Fast, lightweight vanilla HTML/CSS/JavaScript with responsive layout across desktop and mobile.

## 💻 Local Development

To run locally without a build tool:

```bash
# Clone the repository
git clone https://github.com/naqibUVa/academic-portfolio.git
cd academic-portfolio

# Start a local static server (Python 3)
python3 -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.
